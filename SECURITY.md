# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:
<https://github.com/jmuise/library/security/advisories/new>

Do not open public issues or pull requests for security problems. Include what
you found, how to reproduce it, and the version or image digest affected.

## Supported versions

The project is pre-release. Only the latest published image and the `main`
branch are supported. Semantic versioning with release-please is planned; once
tagged releases exist, this section will say which release lines receive fixes.
